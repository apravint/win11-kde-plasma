> **A turnkey, pixel-perfect Windows 11 transformation suite for KDE Plasma 6.**  
> Built for performance, aesthetics, and ease of installation with automatic configuration backups.

![Windows 11 Dark Bloom Preview](assets/win11_bloom_dark.jpg)

---

## ✨ Features

- **Centered Taskbar Layout**: Centered launcher and pinned task icons with glowing active pill indicators.
- **Windows 11 Caption Buttons**: Minimize, Maximize, and Close titlebar decorations matching Windows 11 styling.
- **Segoe UI Variable Typography**: Full suite of Segoe UI fonts mapped across system UI, menus, and window titles.
- **Dark Bloom 4K Wallpaper**: Windows 11 flagship dark bloom wallpaper pre-configured.
- **Corner "Show Desktop" Button**: Recreates the bottom-left/bottom-right Windows peek and reveal button.
- **Natural Language Clock**: Beautiful desktop text clock widget.
- **Automated Backup & Restore**: Automatically saves your previous Plasma setup to `~/.config/plasma-backup-...` before applying changes.

---

## 🚀 Quick Install

Run this in your terminal:

```bash
git clone https://github.com/apravint/win11-kde-plasma.git
cd win11-kde-plasma
./install.sh
```

*(Tip: Log out and back in once to ensure all taskbar geometry settles perfectly).*

---

## 🗑️ Uninstallation & Rollback

To restore your previous KDE Plasma desktop:

```bash
cd win11-kde-plasma
./uninstall.sh
```
